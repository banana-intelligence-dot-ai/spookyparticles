# Optional email for bills and renewals

The Gmail inbox is optional and available by request. Google has not finished verifying the app. You do not need Gmail to watch Vercel schedules or failed deploys.

## What it adds

A read-only Gmail connection can add bills and renewals to your record. Spend appears as a column on a page.

The inbox does not send, change or delete mail. No person reads your mail unless you ask, one message at a time.

## What remains central

The Vercel and GitHub connections show projects, deploys, domains and schedules. A read token watches schedule runs without a code change. Failed deploy alerts include the build log line that names the cause.

Your coding agent can ask what is broken through an API key that reads by default and the MCP server. See [how the map works](/how/apps-across-hosts-and-logins) or the [privacy policy](/privacy) for the data rules.
