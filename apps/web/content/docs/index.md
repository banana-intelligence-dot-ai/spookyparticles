# Spooky Particles docs

Spooky is a pager for people who ship on Vercel with coding agents. It watches deploys, GitHub Actions and scheduled jobs. It alerts your coding agent, and your people if it isn't fixed.

Free, requires your own coding agent.

New here? [VibeOps](/vibeops) says what the work is. [Automate fixes](/automate-fixes) sets up fixes by your coding agent, step by step.
